# Мини-Склад

Учебный проект для стажировки КБ99.

## Структура конфигурации

### Справочники
- **Контрагенты** — поставщики и покупатели
  - Табличная часть: Контактные лица
- **Товары** — номенклатура
  - Табличная часть: Штрихкоды

### Документы
**Поступление товаров** — приёмка от поставщиков
  - ТЧ "Товары": Наименование, Количество, Цена, Сумма
  - Автопересчёт сумм
**Реализация товаров** — отгрузка покупателям
  - ТЧ "Товары": Наименование, Количество, Цена, Сумма, СуммаСоСкидкой
  - Автопересчёт сумм

## Как развернуть

1. Клонировать репозиторий
2. В Конфигураторе: Конфигурация → Загрузить конфигурацию из файлов
3. Обновить базу данных (F7)
